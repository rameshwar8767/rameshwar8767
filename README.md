## 🚀 Featured DevOps & Cloud Projects

### ⚙️ [terraform-aws-ec2-nginx](https://github.com/rameshwar8767/terraform-aws-ec2-nginx)
Infrastructure as Code project provisioning AWS infrastructure end-to-end with Terraform.

- Provisions **EC2, S3, Security Groups, Key Pair**, and networking on the default VPC
- Uses **user-data scripting** to auto-install and configure **Nginx** on instance boot, serving a static site automatically on launch
- Fully reusable via Terraform **variables** and **outputs**
- Complete lifecycle: `terraform init` → `validate` → `plan` → `apply` → `destroy`

**Tech:** Terraform • AWS (EC2, S3, IAM, Security Groups) • Nginx • Bash
