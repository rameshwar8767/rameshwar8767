## 🚀 Featured Projects

### ☸️ LearnStack — Kubernetes Portfolio Project
A hands-on Kubernetes deployment of a full React/Vite application, built to demonstrate container orchestration fundamentals.
- Local multi-node cluster provisioned with **kind**
- Complete manifest suite: Deployments, Services, ConfigMaps, Secrets, Ingress
- Designed to showcase real-world K8s workflows end-to-end

**Tech:** Kubernetes • kind • React • Vite • Docker

---

### 🛒 ShopFusion — Full-Stack E-Commerce Platform
MERN e-commerce platform with an integrated ML microservice for product recommendations, fully containerized and deployed with automated CI/CD.
- **FastAPI microservice** implementing Market Basket Analysis (Apriori / FP-Growth) for recommendations
- **Dockerized** with multi-container orchestration via Docker Compose
- **Jenkins CI/CD pipeline** on AWS EC2 with GitHub Webhooks for automated builds and deploys
- Debugged cross-stack issues spanning React/Redux, Node.js/Mongoose, and the Python ML engine

**Tech:** React • Redux • Node.js • Express • MongoDB • Python (FastAPI) • Docker • Jenkins • AWS EC2

---

### 🔄 Jenkins CI/CD Pipeline on AWS EC2
Standalone DevOps project demonstrating a complete automated deployment pipeline.
- Provisioned and configured an **Ubuntu EC2 instance** (Mumbai region)
- Automated builds triggered via **GitHub Webhooks**
- Docker Hub integration for image publishing
- **Nginx** reverse proxy serving the deployed application
- Hands-on with Linux administration: `systemctl`, `ufw`, AWS Security Groups

**Tech:** Jenkins • Docker • Docker Hub • Nginx • AWS EC2 • Bash
